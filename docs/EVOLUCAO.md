# Evolução e apresentação no portfólio

## Objetivo do experimento

Validar um fluxo de inventário residencial durante mudanças: cadastrar, localizar em caixas, acompanhar transporte e conferir quantidades no destino. O protótipo não promete impedir perdas; ajuda a identificar o que ainda não foi conferido.

## Próximas etapas possíveis

1. Testar o fluxo com uma pequena mudança ou reorganização real, sem depender dele como único registro.
2. Registrar dificuldades e corrigir a experiência de cadastro e conferência.
3. Avaliar fotos e QR Code para identificação de caixas.
4. Definir os requisitos da futura implementação nativa Android: banco local, exportação, acessibilidade e suporte offline.
5. Avaliar sincronização somente depois de definir autenticação, privacidade e conflitos.

## Texto sugerido para o portfólio

**Casa em Ordem — Inventário residencial experimental**

Sistema web responsivo para testar a organização e a conferência de objetos durante uma mudança. Permite cadastrar objetos, organizá-los por cômodo e caixa e acompanhar quantidades embaladas, transportadas e conferidas. Desenvolvido com JavaScript, HTML e CSS, com persistência local, backups JSON e testes de regras de negócio.

**Status:** projeto experimental para testes e aprendizado. Pretendo refazê-lo como aplicativo nativo para Android após validar os fluxos desta versão web.

Esta descrição está preparada para a próxima etapa. O portfólio não é alterado automaticamente por este projeto. Só inclua links para repositório e demonstração depois de publicá-los.
